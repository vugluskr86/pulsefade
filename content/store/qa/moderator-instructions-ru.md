# Инструкция модератору — PULSEFADE

## Запуск игры

Игра запускается сразу: нажмите на страницу (или пробел на десктопе), чтобы начать. Первое кольцо уже в полёте.

## Основной игровой процесс

- Нажимайте в момент, когда движущееся кольцо совпадает с центральной зоной.
- Цвет кольца подсказывает темп: янтарный — быстрее, голубой — медленнее, фиолетовый — сдвоенный удар.
- Раунд длится 30 секунд.

## Доступные режимы

- **Adaptive** — стандартный меняющийся темп (открывается первым).
- **Chaos** — резкие смены темпа.
- **Marathon** — выносливость с ускорением.
- **Zen** — без поражения.
- **Duel** — локальный режим для двух игроков.
- **Daily** — ежедневная последовательность для всех.

## Journey (12 испытаний)

Открывается через кнопку «Испытания Journey» в меню режимов. Испытания открываются последовательно. Оценка: Bronze, Silver, Gold.

## Реклама

### Rewarded (по желанию)

После раунда на экране результата появляется кнопка «×2 PULSES · РЕКЛАМА». Нажатие запускает rewarded-видео. При успешном просмотре игрок получает удвоенную награду pulses. При отсутствии рекламы базовая награда сохраняется.

### Fullscreen (между раундами)

Полноэкранная реклама показывается только на экране результата, не во время игры. Не раньше 4-го раунда, не чаще раза в 3 минуты.

## Проверка таблицы лидеров

Кнопка «Таблица лидеров» на экране результата открывает GamePush leaderboard overlay. Игрок видит топ-20 и свою позицию.

## Проверка сохранений

- Сыграйте раунд, запомните score.
- Обновите страницу (F5).
- Откройте меню → Journey — прогресс должен сохраниться.
- Проверьте, что рекорды видны в лидерборде (при подключённой платформе).
