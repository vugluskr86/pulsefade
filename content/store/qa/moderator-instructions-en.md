# Moderator Instructions — PULSEFADE

## Starting the Game

The game starts immediately: tap or press Space to begin. The first ring is already in flight.

## Core Gameplay

- Tap when the moving ring aligns with the center zone.
- Ring color signals tempo: amber — faster, cyan — slower, violet — double beat.
- A round lasts 30 seconds.

## Available Modes

- **Adaptive** — standard shifting tempo (opens first).
- **Chaos** — sharp tempo changes.
- **Marathon** — endurance with acceleration.
- **Zen** — no failure mode.
- **Duel** — local two-player mode.
- **Daily** — same daily sequence for everyone.

## Journey (12 Trials)

Accessible via the "Journey Trials" button in the mode menu. Trials unlock sequentially. Rating: Bronze, Silver, Gold.

## Advertising

### Rewarded (opt-in)

After a round, the result screen shows a "×2 PULSES · AD" button. Tapping it starts a rewarded video. On successful view, the player receives double pulses. If no ad is available, the base reward is preserved.

### Fullscreen (between rounds)

Fullscreen ads appear only on the result screen, never during gameplay. Not before the 4th round, no more than once every 3 minutes.

## Leaderboard Check

The "Leaderboard" button on the result screen opens the GamePush leaderboard overlay. The player sees the top 20 and their own position.

## Save Check

- Play a round, note the score.
- Refresh the page (F5).
- Open menu → Journey — progress should persist.
- Verify records appear on the leaderboard (if platform is connected).
