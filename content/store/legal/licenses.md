# Лицензии / Licenses

## Звук / Sound

Все звуки игры синтезируются через Web Audio API на лету. Внешние аудиофайлы не используются.

All game sounds are synthesized at runtime via Web Audio API. No external audio files are used.

## Шрифты / Fonts

Игра использует системные моноширинные шрифты, доступные на устройстве игрока (ui-monospace, SF Mono, JetBrains Mono, Roboto Mono, Menlo), и системные sans-serif шрифты. Внешние шрифты не загружаются.

The game uses system monospace fonts available on the player's device (ui-monospace, SF Mono, JetBrains Mono, Roboto Mono, Menlo), and system sans-serif fonts. No external fonts are loaded.
