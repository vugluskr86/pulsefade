# Android / store assets

- `icon-512.png` — исходная квадратная иконка для GamePush Android builder.
- `loading-logo.png` — логотип для splash screen.

В конфиге Android builder относительный путь указывается с префиксом `www/`, например
`www/icons/icon-512.png`. Перед релизом замените эти технические ассеты финальным арт-паком,
сохраняя имена файлов и непрозрачный тёмный фон иконки.
